# Product roadmap

## Free

### 0.1 — Foundation

- [x] Slider post type, unlimited sliders/slides and shortcode rendering
- [x] Drag ordering, editor preview and responsive frontend
- [x] Image, text, video, HTML and shortcode content
- [x] Core controls, navigation and animation presets
- [x] WordPress media picker, basic layer controls and mobile visibility
- [x] Full-width/boxed design controls, overlay, radius and shadow
- [x] Starter template library
- [ ] Gradient controls and independent visibility for every layer/device

### 0.2 — Visual editor

- Layer editing for heading, text, button, image and icon
- Desktop/tablet/mobile previews
- Per-device layer visibility
- Reusable global styles

## Pro

### 1.0 — Commercial foundation

- Dynamic post/custom-post sliders and query builder
- WooCommerce product sources
- Advanced layers and visual motion timeline
- Import/export, version history and analytics
- License/update service for the $19.99 annual plan

### Later milestones

- Figma import and component-based slides
- AI generation with provider keys, consent and usage controls
- Marketing integrations, webhooks and premium templates
- Performance scoring and cloud template marketplace

Features are only marked complete after implementation, security review, accessibility checks and WordPress compatibility testing.
